Frequently Asked Questions

Apa itu Macro Online?

Macro Online adalah portal informasi dan launcher untuk membantu menjalankan paket automation secara lokal di Windows.

Apakah macro berjalan di browser?

Tidak. Browser hanya menyediakan website dan file launcher. Eksekusi dilakukan di komputer Windows pengguna.

Bagaimana jika launcher tidak menemukan start.ps1?

Periksa isi ZIP dan dokumentasi paket. Pastikan paket yang digunakan memang memiliki launcher utama yang sesuai.

Apakah semua macro aman?

Tidak ada jaminan bahwa paket pihak ketiga aman. Periksa sumber dan isi file sebelum menjalankannya.

Mengapa Windows menampilkan peringatan?

BAT dan PowerShell dapat menjalankan perintah lokal. Peringatan keamanan bergantung pada file dan konfigurasi Windows. Jangan melewati peringatan yang tidak kamu pahami.
