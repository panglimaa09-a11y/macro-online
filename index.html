Tentang Macro

Apa itu macro?

Macro adalah rangkaian instruksi atau tindakan otomatis yang dibuat untuk mengurangi pekerjaan berulang. Bergantung pada aplikasinya, macro dapat membantu melakukan klik, input keyboard, menjalankan perintah, atau mengulangi alur kerja tertentu.

Macro Online bukan mesin eksekusi di dalam browser. Portal ini berfungsi sebagai antarmuka informasi dan distribusi launcher. Paket macro yang kamu pilih tetap dijalankan secara lokal oleh komputer Windows kamu.

Cara penggunaan

1

Download launcher

Klik Download Launcher dan simpan run.bat di komputer Windows.

2

Siapkan paket

Letakkan paket macro bernama Macro-Online-FINAL-LOCKED.zip sesuai struktur yang didokumentasikan.

3

Jalankan lokal

Klik dua kali run.bat. Launcher memeriksa ZIP, mengekstraknya, lalu mencari launcher utama.

Eksekusi dilakukan secara lokal di Windows

Website tidak menjalankan macro dari server. Browser hanya mengunduh launcher. Setelah launcher dijalankan, proses ekstraksi dan eksekusi dilakukan di komputer pengguna melalui Windows dan PowerShell. Pastikan kamu memahami dan mempercayai isi paket sebelum menjalankannya.

Keamanan file & penggunaan yang bertanggung jawab

Periksa sumber file

Unduh paket hanya dari sumber yang kamu percaya. Periksa nama, ukuran, dan isi arsip sebelum menjalankannya.

Pahami izin eksekusi

File BAT dan PowerShell dapat menjalankan perintah pada komputer. Jangan menonaktifkan perlindungan keamanan Windows hanya untuk menjalankan paket yang tidak dikenal.

Gunakan lingkungan yang sesuai

Gunakan macro sesuai aturan aplikasi, game, layanan, dan organisasi yang berlaku. Jangan gunakan automation untuk aktivitas yang dilarang oleh layanan terkait.

Backup data penting

Sebelum menjalankan automation yang tidak kamu kenal, simpan pekerjaan dan data penting. Kamu bertanggung jawab atas file dan paket yang kamu pilih untuk dijalankan.

FAQ

Apakah macro berjalan di browser?

Tidak. Browser hanya menampilkan website dan menyediakan file launcher. Eksekusi berlangsung secara lokal di Windows.

Apakah Macro Online menyimpan file macro saya?

Portal ini dirancang sebagai halaman informasi dan distribusi launcher. Paket yang sudah kamu unduh dan jalankan berada di perangkatmu. Jangan mengunggah data sensitif ke layanan apa pun tanpa memahami kebijakannya.

Kenapa Windows/PowerShell bisa memberi peringatan?

File BAT dan PowerShell adalah mekanisme eksekusi lokal. Peringatan keamanan dapat muncul tergantung isi file, reputasi file, dan konfigurasi Windows. Jangan melewati peringatan yang tidak kamu pahami.

Bagaimana jika start.ps1 tidak ditemukan?

Periksa struktur ZIP dan pastikan paket yang digunakan memang memiliki launcher utama yang sesuai dokumentasi. Jangan mengganti file sistem dengan script acak dari sumber tidak tepercaya.

Apakah Macro Online menjamin semua macro aman?

Tidak. Keamanan bergantung pada isi paket dan sumbernya. Selalu periksa file sebelum menjalankannya.
