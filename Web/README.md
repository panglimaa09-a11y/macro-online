# Macro Online

Macro Online is a web control center for MacroForge Runtime.

## Architecture

Vercel:
- Web UI
- Dashboard
- Control interface

Windows:
- Macro Online Runtime
- MacroForge Engine V7.4

The Windows Runtime remains responsible for Windows keyboard/mouse input.

## Current Engine

Engine V7.4

Sequence:

LMB -> RMB -> LMB -> Q -> Q

Trigger:

Physical RMB
