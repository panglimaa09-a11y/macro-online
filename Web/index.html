Pertama Kali

Jalankan Runtime dari PowerShell

Copy satu blok PowerShell, buka Windows PowerShell, paste, lalu Enter. Paket resmi diunduh dari GitHub dan Runtime + Engine + tunnel dijalankan otomatis.

PowerShell — One Command Setup & Start
$ErrorActionPreference='Stop'; $u='https://github.com/panglimaa09-a11y/macro-online/archive/refs/heads/main.zip'; $z=Join-Path $env:TEMP 'macro-online-main.zip'; $d=Join-Path $env:USERPROFILE 'Macro Online'; Invoke-WebRequest -UseBasicParsing $u -OutFile $z; if(Test-Path $d){Remove-Item $d -Recurse -Force}; Expand-Archive $z -DestinationPath $env:TEMP -Force; Move-Item (Join-Path $env:TEMP 'macro-online-main') $d; Remove-Item $z -Force; powershell.exe -ExecutionPolicy Bypass -File (Join-Path $d 'Runtime\\START-PUBLIC-RUNTIME.ps1')

Setelah Enter, Runtime akan membuka dashboard melalui tunnel secara otomatis. Biarkan window Runtime tetap terbuka.

Cara Pakai

Aktifkan Macro

01 — STARTJalankan command PowerShell satu kali.
02 — ONLINETunggu sampai Runtime Online dan dashboard terbuka otomatis.
03 — AKTIFKANKlik AKTIFKAN MACRO. Dashboard mengirim F6 ke Engine.
04 — TRIGGERTekan Physical RMB untuk memulai macro.
05 — SEQUENCELMB → RMB → LMB → Q → Q.
06 — SELESAIMacro selesai setelah Q kedua.
07 — OFFKlik MATIKAN MACRO. Dashboard mengirim F7.
08 — TUTUPBaru tutup Runtime jika sudah selesai.
