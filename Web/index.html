Macro Online

Macro Online adalah control center berbasis web untuk mengendalikan MacroForge Runtime di Windows. Website ini menjadi interface kontrol, sedangkan Engine V7.4 berjalan secara lokal di PC Windows. Setelah Runtime terhubung, kamu dapat mengaktifkan atau mematikan macro dari dashboard. Macro menggunakan Physical RMB sebagai trigger dengan sequence LMB → RMB → LMB → Q → Q.

Full Instructions

Panduan Lengkap Penggunaan

1. Download & Extract

Klik tombol DOWNLOAD ZIP di atas. Setelah selesai, ekstrak ZIP ke folder yang mudah ditemukan, misalnya Downloads\Macro Online.

2. Jalankan Runtime

Masuk ke folder hasil ekstrak dan jalankan RUN-MacroOnline.bat. Runtime akan melakukan build, menjalankan Runtime Agent, lalu membuat Secure Public Tunnel.

3. Tunggu RUNTIME ONLINE

Jangan tutup jendela terminal. Tunggu sampai muncul tulisan RUNTIME ONLINE dan baris WS URL dengan format wss://...trycloudflare.com/?token=....

4. Hubungkan ke Dashboard

Salin seluruh WS URL termasuk bagian ?token=.... Tempel ke kolom Runtime Agent WS URL pada dashboard Macro Online, kemudian klik SIMPAN & HUBUNGKAN. Jika berhasil, indikator berubah menjadi Runtime Online.

5. Aktifkan Macro

Setelah Runtime ONLINE, klik AKTIFKAN MACRO. Status Macro akan berubah menjadi ON. Runtime meneruskan perintah ke Engine V7.4 lokal.

6. Gunakan Trigger RMB

Masuk ke aplikasi/game yang akan digunakan. Saat macro aktif, Physical RMB menjadi trigger. Ketika RMB ditekan, Engine menjalankan sequence LMB → RMB → LMB → Q → Q.

7. Matikan Macro

Untuk menghentikan fungsi macro, kembali ke dashboard dan klik MATIKAN MACRO. Status akan kembali menjadi OFF.

Penting: Runtime terminal harus tetap berjalan selama Macro Online digunakan. Jika terminal ditutup atau Secure Tunnel berhenti, dashboard akan kehilangan koneksi. Jangan bagikan WS URL/token kepada orang lain karena URL tersebut memberikan akses ke Runtime yang sedang berjalan.
