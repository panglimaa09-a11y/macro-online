Macro Online

Macro Online adalah control center berbasis web untuk mengendalikan MacroForge Runtime di Windows. Klik START MACRO ONLINE untuk memulai launcher Windows. Setelah Runtime dan tunnel aktif, dashboard akan mencoba terhubung otomatis. Engine V7.4 tetap berjalan lokal di PC Windows dengan sequence LMB → RMB → LMB → Q → Q.

Setup

Cara Pertama Kali

01 — Download ZIPDownload dan ekstrak paket Macro Online ke folder permanen di Windows.
02 — Install StartDi folder hasil ekstrak, jalankan INSTALL-START-PROTOCOL.ps1 satu kali sebagai user Windows.
03 — Klik STARTKembali ke website dan klik START MACRO ONLINE. Launcher akan membuka Runtime + tunnel.
04 — HubungkanJika diminta, masukkan WS URL dari jendela Runtime lalu klik Simpan & Hubungkan.
Usage

Setelah Runtime Online

05 — ONLINEPastikan indikator kanan atas berubah menjadi Runtime Online.
06 — AKTIFKANKlik AKTIFKAN MACRO. Status Macro berubah menjadi ON.
07 — MAINDi game, tekan Physical RMB untuk menjalankan LMB → RMB → LMB → Q → Q.
08 — MATIKANJika selesai, klik MATIKAN MACRO. Jangan tutup Runtime saat masih digunakan.

Macro Online belum siap

Runtime Windows belum terhubung. Agar tombol START dapat menyalakan Runtime secara otomatis, paket Macro Online harus sudah di-download dan Start Protocol harus dipasang satu kali.
