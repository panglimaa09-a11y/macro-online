Informasi umum

Informasi di Macro Online disediakan untuk tujuan edukasi, dokumentasi, dan penggunaan automation secara bertanggung jawab. Kami tidak menjamin bahwa setiap informasi cocok untuk semua perangkat atau aplikasi.

File dan script

Launcher dan paket macro dapat menjalankan proses lokal di Windows. Pengguna harus memeriksa sumber dan isi file sebelum menjalankannya. Macro Online tidak bertanggung jawab atas paket pihak ketiga yang diperoleh dari sumber lain.

Layanan pihak ketiga

Nama, aplikasi, game, merek, atau layanan pihak ketiga yang disebut di situs tetap menjadi milik pemilik masing-masing. Pengguna wajib mengikuti ketentuan mereka.

Batas tanggung jawab

Penggunaan launcher, macro, dan script dilakukan atas risiko pengguna sendiri. Pastikan data penting dicadangkan dan perlindungan keamanan perangkat tetap aktif.
